# Decision Wheel

A lightweight standalone spin wheel app built for FreeAppStore.

## Features

- Add custom options
- Delete options
- Reset all options
- Spin wheel animation
- Random result selection
- Responsive layout
- Dark mode support
- PWA support
- Offline-ready after first load
- localStorage persistence
- No tracking, analytics, or accounts

## Tech Stack

- TypeScript
- React 19
- Vite
- Tailwind CSS 4
- PWA
- pnpm workspace

## Development

Install dependencies:

```bash
pnpm install
```

Run locally:

```bash
pnpm dev
```

Build production bundle:

```bash
pnpm build
```

Run typecheck:

```bash
pnpm typecheck
```
